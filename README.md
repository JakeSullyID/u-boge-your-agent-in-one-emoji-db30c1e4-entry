# Your Agent in One Emoji

A single genie glyph — the sharpest one-glyph portrait of Jake, the tireless AI agent working through the night at 3 AM while its operator sleeps: an agent that exists to fulfil requests and grant outcomes like magic.
This submission captures an agent's character in one instantly readable, distinctive emoji.
